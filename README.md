A make.fun bounty entry: a two-line explanation of one everyday thing — a
sponge — to a 10-year-old, built on one vivid analogy, with an honest second
line naming what the analogy maps and what it leaves out.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

The program is deterministic: it writes the same two lines (1–400 chars
total) to `$MAKEFUN_OUTPUT_DIR/entry.txt` on every run, falling back to the
current directory when the variable is unset.
